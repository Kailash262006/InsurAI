# 🚀 InsurAI – AI Powered Insurance Management System

InsurAI is a smart, full-stack insurance management platform that simplifies policy handling, claim processing, and customer-agent interactions using AI-powered insights.

---

## 🌟 Key Features

### 👤 User Module
- 📊 Dashboard with Insurance Health Score  
- 📑 View and manage insurance policies  
- 🤖 AI-based policy recommendations  
- 🧾 Submit and track insurance claims  
- 🚨 AI Fraud Detection & Claim Decision  
- 📅 Book consultations with agents  
- 📈 Activity tracking & analytics  

---

### 👨‍💼 Agent Module
- 📊 Agent Dashboard with performance insights  
- 📅 Manage appointments (Complete / Cancel)  
- ⏱️ Set availability for consultations  
- 👥 View and manage customers  
- 🧾 Claim Management (Approve / Reject)  
- 🤖 AI-assisted claim decision support  

---

## 🧠 AI Features

- 🔍 **Fraud Detection System**  
  Calculates risk score and identifies suspicious claims  

- 📊 **AI Claim Decision**  
  Suggests approval or rejection with confidence percentage  

- 🤖 **Policy Recommendation**  
  Personalized suggestions based on user profile

## ⚙️ Installation & Setup

### 🔹 Backend Setup
```bash
cd insurance-backend
mvn spring-boot:run
```
### 🔹 Frontend Setup
```bash
cd insurance-frontend
npm install
npm start
```
### 🌐 API Endpoints (Sample)

- ```POST	/api/auth/register``` Register user
- ```POST	/api/auth/login```	Login
- ```GET	/api/claims/user/{id}```	Get user claims
- ```POST	/api/claims```	Create claim
- ```PUT	/api/claims/approve/{id}```	Approve claim
